# Saudável Mente - Care Plus Digital 💚

O **Saudável Mente** é uma solução inovadora desenvolvida para o Challenge FIAP em parceria com a Care Plus. O objetivo principal do ecossistema é reduzir drasticamente a taxa de *no-show* (não comparecimento) em consultas médicas, utilizando pilares de gamificação ativa e inteligência de percurso.

## 🚀 Funcionalidades da Sprint 2
- **Interface Responsiva:** Desenvolvida com Bootstrap 5.3, garantindo adaptação total para dispositivos móveis e desktops.
- **Inteligência de Percurso:** Simulação de cálculo de trânsito em tempo real para alertar o paciente sobre o horário ideal de saída.
- **Gamificação Integrada:** Sistema de pontuação (recompensas e tiers) para engajar o paciente a confirmar ou reagendar consultas com antecedência.
- **Feedback Dinâmico:** Uso de componentes nativos e Toasts do Bootstrap para notificações de ações do usuário (como login e confirmações).

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3 (Customizado com variáveis de estilo e transições)
- JavaScript (Lógica de dinamismo e manipuladores de eventos)
- Bootstrap 5.3 (Framework web para design e responsividade)
